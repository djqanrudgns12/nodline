# 노드라인 (Nodeline)

플레이어가 산과 강이 존재하는 지형 위에 지하철 노선을 연결하고, 열차를 운행하여 승객을 목적지까지 이동시키는 2D 지하철 건설/운영 시뮬레이션 게임입니다.

## 핵심 규칙

- **게임오버**: 어느 한 역의 대기 승객이 **15명**에 도달하면 게임이 종료됩니다.
- **역당 노선 제한**: 한 역에 최대 **5개** 노선까지 연결할 수 있습니다.
- **객차 수용 인원**: 객차당 최대 **5명**까지 탑승 가능합니다.
- **지형 장애물**: 강을 통과하려면 **다리**, 산을 통과하려면 **터널**이 필요합니다.

## 게임 루프

```
노선 연결 → 열차 운행 → 승객 증가 → 병목 발생 → 노선 수정 → 혼잡 해소
```

## 조작법

| 키 | 기능 |
|---|---|
| Space | 일시정지/재생 |
| 1, 2, 4 | 1배속, 2배속, 4배속 |
| L | 노선 도구 |
| B | 다리 도구 |
| T | 터널 도구 |
| U | 실행 취소 |
| R | 다시 실행 |
| S | 저장 |
| Esc | 취소 |
| 마우스 휠 | 줌 |
| 마우스 중간 버튼 드래그 | 카메라 이동 |

## 기술 스택

- **엔진**: Godot 4.7.2 Standard
- **언어**: GDScript
- **플랫폼**: Windows x64 (오프라인, 로컬 실행)
- **아키텍처**: 클린 아키텍처 + CQRS + 데이터 중심 설계

## 프로젝트 구조

```
res://
├─ app/
│  ├─ bootstrap/         # 게임 매니저 (오케스트레이터)
│  ├─ application/       # 유즈케이스, 명령, 쿼리
│  ├─ domain/            # 엔티티, 규칙, 서비스, 이벤트
│  ├─ infrastructure/    # 저장, 로그, 직렬화
│  └─ presentation/      # 씬, UI, 컨트롤러
├─ assets/               # 폰트, 오디오, 아이콘
├─ data/balance/         # 밸런스 설정 리소스
├─ docs/adr/             # 아키텍처 결정 기록
└─ tests/                # 단위/통합/스모크 테스트
```

## 빌드

```bash
# Godot 에디터에서 실행
# 또는 CLI:
godot --export-all
```
