# ADR D-01: TCREI 원칙 정의

## 상태: 확정

## 결정
A 방식 (표준 정의) 채택

## 상세
PRD 3.1절에 정의된 5대 기준을 프로젝트 전반에 강제한다:
- **T (Traceability)**: 추적 가능성 — 요구사항 → 기능 → 규칙 → 테스트 → 이벤트 1:1 연결
- **C (Consistency)**: 일관성 — 같은 의미는 같은 데이터/UI 패턴으로 표현
- **R (Resilience)**: 복원력 — 잘못된 조작/저장 오류 시 복구 가능
- **E (Extensibility)**: 확장성 — 데이터/정책 추가로 확장 가능
- **I (Implementability)**: 구현 가능성 — 추측 없는 명확한 규칙 정의

## 영향
- 프로젝트 전체 아키텍처 및 코드 리뷰 기준

# ADR D-16: 인프라 접근성 보장 및 2개 장애물 원천 차단

## 상태: 확정

## 결정
다리 >= 2개 또는 터널 >= 2개 필요 배치 원천 차단 알고리즘 채택

## 상세
- 시작 시 다리 1개, 터널 1개가 주어지므로, 신규 역 생성 시 기존 역들과 연결하는 데 다리가 2개 이상 또는 터널이 2개 이상 필요한 고립 배치를 엄격히 금지
- 기존 역 중 최소 1개 이상의 역과 `다리 <= 1` AND `터널 <= 1`로 연결 가능한 위치만 유효 위치로 승인
- 유효하지 않은 배치는 자동 리젝 후 재추첨하여 플레이어가 인프라 한계로 인해 막히는 현상 원천 방지

# ADR D-17: 순환선 무결성 보존 및 분기 노선 연결 규칙

## 상태: 확정

## 결정
순환선(`isCircular == true`)과 다른 역을 연결할 때 순환선을 깨뜨리지 않고 그대로 유지하며, 여분 호선(신규 노선) 또는 연장 가능한 다른 비순환 노선으로 분기 연결한다.

## 상세
- 완성된 순환선의 루프 구조와 순환 운행은 절대 해제되거나 변형되지 않는다.
- 순환선 소속 역은 환승 거점 역할을 수행하며, 다중 환승 BFS(`computeRideDistances`)를 통해 순환선 ↔ 분기 노선 간 승객 환승을 지원한다.

# ADR D-25: 역 최대 인원(30명) 대비 열차 최대 인원 2:1 비율(15명 고정) 및 객차 추가 규칙

## 상태: 확정

## 결정
- 역 최대 수용 한도(게임오버 임계값)를 `30명`으로 설정한다.
- 역 최대 수용 인원(`30명`)에 대한 열차 1대 최대 수용 인원의 비를 `2 : 1`로 두어 열차 최대 정원을 정수 `15명`(`Math.round(30 * 1 / 2) = 15`)으로 고정한다.
- 주간 5종 보급(`호선 추가`, `객차 추가`, `역 추가`, `다리 추가`, `터널 추가`) 중 `객차 추가` 선택 시, 열차 최대 정원(15명)은 유지하고 기존 운행 노선에 새 열차 1대(정원 15명)를 추가 투입한다.

- `W` 키를 누르면 각 개통 노선별로 가장 최근에 연결된 종점/분기 역의 위치에 호선 색상 배지와 펄싱 링을 캔버스 위에 실시간 하이라이트 표시하고 토글(On/Off)한다.
- 좌측 도구 레일에도 `#btnToolLastStation` (`종점 · W`) 버튼을 배치하여 마우스 클릭으로도 직관적으로 켜고 끌 수 있도록 지원한다.
- 후반부 노선 수가 많아지고 맵이 확장되었을 때 각 노선의 종점 위치를 즉시 식별할 수 있도록 가독성을 극대화한다.

# ADR D-30: Q+(숫자) 조합 단축키 배속 제어(1~10배속) 및 동적 HUD 인디케이터 지원

## 상태: 확정

## 결정
- `Q` 키와의 조합을 통해 시뮬레이션 배속을 **1배속부터 10배속(`1~10x`)**까지 자유롭게 조절할 수 있도록 단축키 체계를 확장한다.
  - `Q` 키를 누른 채 숫자 `1` ~ `9` 입력: 즉시 해당 배속(`1x` ~ `9x`)으로 설정.
  - `Q` 키를 누른 채 숫자 `0` 입력 (또는 `Q` 누른 상태에서 `1`, `0` 연속 입력): 즉시 `10x`(10배속)으로 설정.
  - `Q` 키 단독 탭 시: 1.8초 동안 "배속 설정 모드"가 활성화되어 `Q`를 계속 누르고 있지 않아도 연이어 숫자 키를 누르면 배속이 변경되는 시퀀스 프리픽스 모드 지원.
- `Q` 키가 눌려있지 않은 단독 숫자 키 `1` ~ `9`는 기존 호선 슬롯 직접 지정(ADR D-18 / ADR D-24)으로 온전히 유지되어 키 충돌을 완전 배제한다.
- 한영 전환 상태(한글 IME의 'ㅂ' 키 입력)에서도 `e.code === 'KeyQ'` 및 한글 키코드 대응을 통해 한/영 모드에 구애받지 않고 100% 동작한다.
- 상단 HUD 배속 카드(`#hud-card.speed-card`)에 동적 인디케이터(`#btnSpeedCustom`)를 추가하여, 기본 1x/2x/4x 외의 배속(3x, 5x~10x) 설정 시에도 실시간 배속 수치가 표시 및 활성화된다.

# ADR D-31: 초기 진입 조작법 안내 모달 UI 및 닫기 기능

## 상태: 확정

## 결정
- 게임 최초 진입 시 신규 플레이어가 핵심 조작 및 규칙을 한눈에 파악할 수 있도록 간결한 조작법 안내 UI 모달(`#controlsGuideModal`)을 표시한다.
- 모달 하단에 명확한 `닫기` 버튼(`#btnCloseControlsGuide`)과 상단 우측 `✕` 닫기 버튼(`#btnCloseControlsGuideX`)을 제공하며, `Escape`, `Enter`, 모달 배경 클릭 시에도 즉시 닫힌다.
- 안내 내용 구성:
  1. **마우스 조작**: 좌클릭(역 연결), 우클릭/드래그(화면 이동), 휠 스크롤(줌 40%~280%), 우클릭/ESC(연결 취소).
  2. **키보드 단축키**: `Space`(일시정지), `Q+1~9, 0`(1~10배속), `1~9`(호선 지정), `W`(종점 하이라이트), `C`(중앙 정렬), `U/R`(실행 취소/복구).
  3. **핵심 규칙 & 팁**: 역 30명 한도 및 2:1 정원(열차 15명), 다리/터널 인프라 자동 건설, 주간(7일) 맵 1/6 확장 및 5종 보급 선택.
- 게임 중 언제든 다시 확인할 수 있도록 좌측 도구 바에 `도움 · H` 버튼(`#btnToolHelp`)을 추가하고, 키보드 `H` 또는 `?` 단축키를 지원한다.
